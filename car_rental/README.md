# Car Rental KH – Full-Stack Flask App

A **complete, professional car rental system** built with **Flask (Python)** and **Jinja2 HTML templates**.  
Includes **Customer, Staff, and Admin** roles with full CRUD, QR payments, invoices, damage reports, and image uploads.

---

## Features

| Role | Features |
|------|---------|
| **Customer** | Register/Login, Browse Cars, Book, Promo Codes, QR Payment, View Invoice, Print |
| **Staff** | Dashboard, Check-In/Out, Report Damage, Update Car Images, View History |
| **Admin** | Full control: Manage Cars, Users, Bookings, Promos, View Damage Reports |

---

## Tech Stack

- **Backend**: Python + Flask
- **Frontend**: HTML, CSS, Jinja2
- **Database**: In-memory (ready for SQLite)
- **QR Code**: `qrcode[pil]`
- **File Upload**: `static/car_images/`
- **Styling**: Responsive CSS
